# Sensor de Movimento

Projeto em Python que acessa a webcam e exibe o vídeo em tempo real usando OpenCV. A captura continua até que a tecla `Q` seja pressionada.

## Requisitos

- Python 3.14 ou superior
- `uv`
- Uma webcam conectada

## Instalação

Clone o repositório e entre na pasta:

```bash
git clone https://github.com/Thy281/sensor-movimento.git
cd sensor-movimento
